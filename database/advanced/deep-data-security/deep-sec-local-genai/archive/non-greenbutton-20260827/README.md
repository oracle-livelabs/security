# Archived non-GreenButton Deep Sec paths

Archived on 2026-08-27 when GreenButton became the canonical Deep Sec build.

This directory preserves the former wallet-based application sources, regular
Terraform Stack, NO-IAM and FREE variants, package builders, ZIPs, download
sidecars, and workshop material. Do not use these files for new deployments.

Use the active `greenbutton-files/`, `terraform-greenbutton/`, and
`deep-sec-local-genai-terraform-GreenButton.zip` at the repository root.
